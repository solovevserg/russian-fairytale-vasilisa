# Василиса Прекрасная — 3D-сказка

Интерактивная история для браузера по русской народной сказке «Василиса Прекрасная» (по мотивам собрания А. Н. Афанасьева). Справа — текст с буквицами и виньетками в духе Билибина, слева — трёхмерный дремучий лес с избушкой на курьих ножках. По мере чтения меняются время суток, ракурс камеры и происходящее в сцене.

**Сайт:** <https://sergsol.dev/russian-fairytale-vasilisa/>

## Что внутри

- **Скроллителлинг.** Каждой главе соответствует ключевой кадр: камера летит по сплайну, время суток идёт вперёд от ночи к рассвету, проносятся белый, красный и чёрный всадники, загораются глаза черепов на частоколе, по небу летит Баба Яга в ступе.
- **Процедурный лес** из [ez-tree](https://github.com/dgreenheck/ez-tree) с собственным шейдером ветра, трава, кусты, рельеф, тропинка, облака, звёзды, дым из трубы.
- **Звук:** «Картинки с выставки» Мусоргского, звуки леса, скрип избы и треск деревьев с пространственным звучанием.
- **Чтение:** автопрокрутка от главы к главе и озвучка голосом браузера (Web Speech API).
- Светлая и тёмная темы, мобильный макет.

## Разработка

Нужен [Bun](https://bun.sh) 1.3+.

```sh
bun install
bun run dev          # http://localhost:5173/russian-fairytale-vasilisa/
bun run check        # Biome: линтинг и форматирование
bun run typecheck    # TypeScript
bun run test         # юнит-тесты (bun test)
bun run test:e2e     # e2e-тесты (Playwright; первый раз: bunx playwright install chromium)
bun run build        # сборка в dist/
```

Перед коммитом Husky запускает Biome на изменённых файлах, проверку типов и юнит-тесты.

Полезные параметры адреса для отладки: `?time=21` — зафиксировать время суток, `?noforest`, `?nograss`, `?noshadows`, `?noleaves` — отключить части сцены (замеры производительности), `?readtime=2` — короткая пауза автопрокрутки, `?quality=low|medium|high` — принудительный уровень качества (по умолчанию выбирается по устройству, сети и видеокарте, а разрешение холста подстраивается по fps; в дев-сборке выбор пишется в консоль).

Язык — `?lang=ru|en|es|zh` (по этим адресам ссылаются `hreflang` в `index.html` и `public/sitemap.xml`). Превью ссылок — `public/og-image.jpg` (1200×630, кадр главы «Чёрный всадник» с названием).

Ассеты готовятся скриптами (результат уже лежит в `public/`):

```sh
bun run audio:prepare      # скачать и перекодировать звук (Opus/WebM + MP3)
bun run textures:prepare   # скачать текстуры земли с Poly Haven и перекодировать в WebP
```

## Устройство

```text
src/
  story/       тексты глав, ключевые кадры сцены, таймлайн (чистые функции)
  scene/       3D: лес, земля, трава, небо и свет, избушка, персонажи
  audio/       звуковой движок на Web Audio
  reader/      автопрокрутка и озвучка
  ui/          колонка текста, орнаменты, панель управления
docs/          спецификация, сценарий, реестр ассетов и лицензий
tests/         юнит- (bun test) и e2e-тесты (Playwright)
```

Подробнее — в [спецификации](docs/SPEC.md) и [сценарии](docs/scenario.md).
