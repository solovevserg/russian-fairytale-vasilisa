# Сценарий: «Василиса Прекрасная»

Основа — запись А. Н. Афанасьева («Народные русские сказки», № 104), общественное достояние. На сайте — сокращённая редакция: линия «Василиса идёт к Бабе Яге за огнём и возвращается».

Каждая глава = один ключевой кадр сцены (`src/story/keyframes.ts`, см. §4 [SPEC.md](SPEC.md)). Время суток в сказке задают всадники. Солнце встаёт со стороны избушки, если смотреть с тропы, — Василиса идёт навстречу рассвету. Дым из трубы идёт во всех главах; птицы кружат днём и в сумерках.
